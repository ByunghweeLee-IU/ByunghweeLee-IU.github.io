FUNCTION

y(r; β)

● 함수┄ 기준선 y = r

SECOND DERIVATIVE

∂²y / ∂r²

● 2차 미분세로축 자동 조절

정의역: 0 ≤ r ≤ 1 · β 범위: −3 ≤ β ≤ 6 · 2차 미분은 β를 고정하고 r에 대해 계산합니다. 두 그래프의 세로축 범위는 서로 다릅니다.

2차 미분 계산식

a = exp(−2β), N = r³ + ar(1−r²), D = (1−r)³ + r³ + 3ar(1−r)로 놓으면:

y″ = N″/D − (2N′D′ + ND″)/D² + 2N(D′)²/D³

N′ = 3r² + a(1−3r²), N″ = 6r(1−a)
D′ = 3(a−1)(1−2r), D″ = 6(1−a)

유한한 β와 이 정의역에서 D > 0입니다. 2차 미분 그래프는 위 해석식을 직접 계산합니다.
